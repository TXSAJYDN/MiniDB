MiniDB v0.1.0 是项目的首个公开正式基线：面向有界资源的单机
crash-consistent KV 存储服务。该版本是可靠性工程原型，不是生产服务。

## 核心能力

- HTTP/1.1 子集与二进制安全 TCP KV 前端，共享同一 WAL、RDB、checkpoint 和 manifest；
- `SYNC`/`INTERVAL` durability、CRC32C WAL、严格 LSN、segment 轮转和原子 checkpoint 发布；
- 有界组提交、异步 mutation、后台全量 checkpoint 和单写者锁；
- Snapshot Isolation、first-committer-wins、per-key 版本链和单记录 `kTxn` 原子事务；
- 二进制 `AGENT=12` 持久 Agent 状态后端，支持 session、tool、lease/fence、generic record 和幂等重放；
- C01-C14 崩溃点、恢复 fail-stop、TTL/GC、资源上限和诊断 stats。

## 验证

- 六种构建配置各 440/440 CTest：Debug、Release、ASan、UBSan、ASan+UBSan、TSan；
- 31 个进程级集成用例；
- 六个固定 seed fuzz target；
- 发布工作流只在 tagged commit 自身的 GitHub Actions 9/9 成功后创建 Release。

详细证据见 [可靠性证据](https://github.com/TXSAJYDN/MiniDB/blob/main/docs/reliability-evidence.md)
和 [CHANGELOG](https://github.com/TXSAJYDN/MiniDB/blob/main/CHANGELOG.md)。

## 已知边界

本版本不提供生产 SLA、SQL、Redis 兼容、TLS/认证、复制/共识、多写者或多节点
Agent lease。crash-consistent 结论只覆盖已测试的进程崩溃与重启，不证明掉电、
内核崩溃或介质损坏。
